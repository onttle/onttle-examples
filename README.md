# Onttle Examples

Example websites that use [Onttle](https://onttle.com) as a headless CMS and REST API. Each example is an independent Next.js app, and the build process is recorded in its `docs/BUILD_LOG.md` (in Korean).

| Example | What it is |
| --- | --- |
| [blog](blog) | A tech blog built on Onttle (list, detail, tags, BM25 search) — [example.onttle.com/blog](https://example.onttle.com/blog) |
| [help-center](help-center) | An AI help center built on Onttle (FAQs, semantic search, AI answers with sources) — [example.onttle.com/help-center](https://example.onttle.com/help-center) |
| [i18n-landing](i18n-landing) | A Korean and English landing page built on Onttle (translations, variables, localized columns, publishable key only) — [example.onttle.com/i18n-landing](https://example.onttle.com/i18n-landing) |

Every example is deployed at `https://example.onttle.com/<name>`. Path routing is handled by [_gateway](_gateway).
