# Onttle Examples

[Onttle](https://onttle.com)을 헤드리스 CMS·REST API로 쓰는 예제 웹사이트 모음입니다. 예제마다 독립된 Next.js 앱이고, 만든 과정을 `docs/BUILD_LOG.md`에 남깁니다.

| 예제 | 내용 |
| --- | --- |
| [blog](blog) | Onttle로 만드는 기술 블로그 (목록·상세·태그·BM25 검색) — [example.onttle.com/blog](https://example.onttle.com/blog) |
| [help-center](help-center) | Onttle로 만드는 AI 헬프센터 (FAQ·의미 검색·출처 달린 AI 답변) — [example.onttle.com/help-center](https://example.onttle.com/help-center) |

모든 예제는 `https://example.onttle.com/<name>`에 배포됩니다. 경로 라우팅은 [_gateway](_gateway)가 맡습니다.

- 문서: https://onttle.com/docs
- 저장소 규칙: [AGENTS.md](AGENTS.md)
