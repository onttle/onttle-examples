Onttle Examples

Example websites that use Onttle as a headless CMS.

  • blogA tech blog built on Onttle (list, detail, tags, BM25 search)
  • help-centerAn AI help center built on Onttle (FAQs, semantic search, AI answers with sources)
  • i18n-landingA Korean and English landing page built on Onttle (translations, variables, localized columns)
  • feedback-boardA members-only feedback board built on Onttle (sign-up, e-mail verification, permission rules, member writes)
  • event-rsvpA login-free meetup RSVP page built on Onttle (REFERENCE column, webhook, secret-key-only table, seat limit)
  • photo-portfolioA photo portfolio built on Onttle (OCR and AI file descriptions as alt text and tags, thumbnail presets, semantic search over file descriptions)
Source: github.com/onttle/onttle-examples
